# tdk_dolgozat
Az alábbiakban a TDK dolgozatomhoz felhasznált R kódok, valamint az elemzéshez használt dokumentumok találhatóak meg.

Fontos megjegyeznem, hogy az adatbázis, melyet az elemzéshez használtam fel nem az én tulajdonom, és nem is publikus, így azt közzé nem tehetem.
Emellett, a CDA résznél szerzői és adatvédelmi okokból több elemzett dokumentumot eltávolítottam. Ezeket opponensi kérésre teszem csak hozzáférhetővé.
